# GourmetEats

Site demonstrativo de receitas culinárias feito com HTML5 e CSS3.

## Estrutura
- `index.html`: página inicial, categorias e receitas em destaque.
- `eventos.html`: área de aniversários, Natal e eventos especiais.
- `css/style.css`: estilos compartilhados e responsividade.
- `receitas/`: páginas individuais das receitas.

## Como executar
1. Extraia a pasta `GourmetEats`.
2. Abra `index.html` no navegador.
3. Para navegar, use o menu e os links dos cartões.

As imagens são carregadas de URLs externas e precisam de internet.
