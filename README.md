# GourmetEats
O "GourmetEats" é um site de receitas desenvolvido em HTML e CSS, com o objetivo de facilitar a busca e a organização de receitas culinárias. Conta com categorias, páginas detalhadas de receitas e sugestões para ocasiões especiais, como aniversários, Natal e confraternizações. O projeto possui layout responsivo e navegação simples e intuitiva.

Site de receitas desenvolvido com **HTML e CSS**, criado para facilitar a busca e a organização de receitas culinárias.

## Funcionalidades
- Categorias de receitas.
- Páginas com ingredientes e modo de preparo.
- Informações sobre tempo, rendimento e dificuldade.
- Receitas para ocasiões especiais, como aniversários e Natal.
- Layout responsivo para computadores e celulares.

## Tecnologias utilizadas
- HTML5
- CSS3

## Como executar
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
