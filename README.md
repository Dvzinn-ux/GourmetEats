# GourmetEats
O "GourmetEats" é um site de receitas desenvolvido em HTML e CSS, com o objetivo de facilitar a busca e a organização de receitas culinárias. Conta com categorias, páginas detalhadas de receitas e sugestões para ocasiões especiais, como aniversários, Natal e confraternizações. O projeto possui layout responsivo e navegação simples e intuitiva.
